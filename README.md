 🤖 AI Code Reviewer Agent
 
📌 Project Description

AI Code Reviewer Agent is an automated code review system that reviews GitHub Pull Requests. 
Whenever a Pull Request is created or updated, the application analyzes the changed files and automatically posts review comments.

 🚀 Highlights

- Automated Pull Request Reviews
- FastAPI Webhook
- GitHub API Integration
- AI-inspired Rule-Based Review
- Automatic Review Comments
- Modular Python Project

   ⚙️ Technologies Used

- Python
- FastAPI
- GitHub API
- PyGithub
- Cloudflare Tunnel
